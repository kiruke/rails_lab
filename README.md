# Rails Lab

Railsの内部動作を実験・観察するための学習環境。

## 目的

Railsの書き方を暗記するのではなく、

- Rubyコード
- Rails
- Active Record
- SQL
- PostgreSQL

の間で何が起きているのかを実際に確認する。

Dockerについても、環境構築を通して理解する。

## 実験テーマ

- CRUD
- Routing / Controller / View
- Active Record
- Association
- Validation
- N+1
- Transaction
- Index
- SQL
- Authentication / Authorization
- Job
- Mailer
- Cache
- API
- Turbo

## Environment

- Ruby
- Rails
- PostgreSQL
- Docker
